FRESHNEST GROCERY FRONTEND SETUP

1. Extract this folder.
2. Open the folder in VS Code.
3. Run: npm install
4. Ensure the backend is running at http://localhost:8080. Check src/services/api.js if your backend uses a different URL.
5. Run: npm start
6. Open the localhost URL shown by Create React App.
7. Run: npm run build to check the production build.

This frontend keeps existing routes, API calls, authentication and cart/order workflows. Grocery product records and their image URLs need to be added through the existing admin interface/database. The frontend does not automatically replace records already stored in MySQL.
